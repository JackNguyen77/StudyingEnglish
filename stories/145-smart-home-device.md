# Story 145 - Điều khiển thiết bị nhà

Audio: [145-smart-home-device.mp3](../audio/145-smart-home-device.mp3)

## 1. Story

I connected the smart speaker because my hands were full.

The first voice command worked, but the second one failed.

I changed the device name so it was easier to say.

A connection drop made the lights turn off for a few seconds.

Later, I used my phone to turn off remotely before leaving home.

If the command failed again, I would check the app first.

That setup step made the device easier to use the next time I needed it.
