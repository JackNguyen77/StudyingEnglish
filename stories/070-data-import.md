## 1. Story

During the call, the customer described the data import in simple words.

I asked about the sample file before I suggested anything.

The real problem was the missing column, not only the first request.

We agreed to clean the data first and check it with one example.

I wrote the import rule so everyone could review the same decision.

That helped us prevent bad records without adding extra work.

By the end of the call, the next step felt clear to both sides.
