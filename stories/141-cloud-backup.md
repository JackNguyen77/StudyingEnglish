# Story 141 - Sao lưu lên cloud

Audio: [141-cloud-backup.mp3](../audio/141-cloud-backup.mp3)

## 1. Story

I turned on cloud backup before changing to a new phone.

Automatic backup ran at night when the Wi-Fi was stable.

I needed to restore the file after I deleted the wrong copy.

The notes could sync across devices, which saved me time.

I checked the storage plan before uploading all my videos.

When backup failed, I kept the app open and tried again.

That backup habit made my files easier to trust the next time I needed them.

## 2. Dịch tự nhiên

Tôi bật sao lưu cloud trước khi đổi sang điện thoại mới.

Sao lưu tự động chạy ban đêm khi Wi-Fi ổn định.

Tôi cần khôi phục file sau khi xóa nhầm bản sao.

Ghi chú có thể đồng bộ giữa các thiết bị, giúp tôi tiết kiệm thời gian.

Tôi kiểm tra gói lưu trữ trước khi tải tất cả video lên.
