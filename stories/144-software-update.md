# Story 144 - Cập nhật phần mềm

Audio: [144-software-update.mp3](../audio/144-software-update.mp3)

## 1. Story

My phone said an update was available, but I was about to leave.

I chose to install overnight so it would not interrupt work.

The release notes mentioned a bug fix for the camera.

That bug fix mattered because my video calls had been freezing.

After the download, the phone asked me to restart the phone.

In the morning, I checked the version and tested the camera.

That setup step made the device easier to use the next time I needed it.
